# Leis Digitais de Angola

Repositório aberto da legislação angolana sobre tecnologias digitais: protecção de dados, comunicações electrónicas, cibercriminalidade e segurança.

> Projecto independente. Não é um site oficial e não substitui o Diário da República nem aconselhamento jurídico.

## Estrutura

```
leis/           um ficheiro Markdown por lei
regulamentos/   decretos e regulamentos
site/           website (Next.js) gerado a partir dos ficheiros acima
indice.json     resumo de todos os documentos (gerado automaticamente)
```

## Correr o site

```bash
cd site
npm install
npm run dev
```
